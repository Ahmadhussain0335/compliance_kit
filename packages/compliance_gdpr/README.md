# compliance_gdpr

**Status: planned.** This package is a placeholder and is not implemented yet. It is not published to pub.dev.

GDPR consent management, data export and account deletion flows for Flutter apps.

See the [root README](../../README.md) for the Compliance Kit package family.

## Disclaimer

Compliance Kit helps developers implement privacy and security controls. It does not by itself make an application compliant with GDPR, the CRA, EN 18031, OWASP MASVS or any other regulation or standard. Compliance depends on the whole system and must be assessed separately.
